To run these codes, you would need Borland Turbo C/C++ compiler and DOSBox emulator. 
The codes cannot be run on modern compilers due to the usage of prehistoric switches like #include<conio.h> and void main() etc. 

You can get the compiler from the following link - 
https://developerinsider.co/download-turbo-c-for-windows-7-8-8-1-and-windows-10-32-64-bit-full-screen/

If you want to try these codes on native hardware, for example, 
a PC with SoundCard or Internal Speakers with MS-DOS based Operating System (eg. Windows 9x, FreeDOS etc.),
You would need Borland Turbo C/C++ installer version 3.0+

Instructions for mounting Turbo C/C++ on DOSBox:

" Z:\mount C: C:\
  Z:\C:\
  C:\cd TurboC3\bin    
  C:\TurboC3\bin\TC "
(sometimes the folder name might be TC instead of TurboC3 so watch out for that)
